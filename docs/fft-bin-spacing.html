頻域

FFT 的頻率格距

從取樣率與樣本數算出相鄰頻率格點的距離。

核心觀念

FFT 是計算離散傅立葉轉換的演算法。對 N 筆等間距樣本做 N 點轉換時，相鄰頻率格點距離為取樣率除以 N。

手算例子

以 256 Hz 取樣，取 128 筆做 128 點 FFT。記錄長度為 128 ÷ 256 = 0.5 秒，頻率格距為 256 ÷ 128 = 2 Hz。

容易混淆的地方

補零可以讓頻譜格點更密，但原本的觀測時間並未增加。相近成分能否分辨仍與觀測長度和窗函數有關。
